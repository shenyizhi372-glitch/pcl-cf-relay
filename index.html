PCL CF Relay

A minimal, self-hosted CurseForge API relay for a personal Plain Craft Launcher installation.

This is a personal-use project. It exists because Plain Craft Launcher 2.13.1.1 ships a hard-coded CurseForge API key that was revoked in 2026, so CurseForge search, version lookup and file downloads fail with 403. Instead of putting an API key inside a client binary, the key stays on my own server.

No key in the clientThe launcher only knows a relay domain. The API key lives in a server-side environment file.
Single userThe relay serves exactly one launcher installation and is not offered as a public API.
Author-friendlyOnly files that authors published on CurseForge / Modrinth are requested, following their distribution settings.
RevocableThe key can be rotated at any time; the relay is shut down if misuse is detected.

Routing

PCL  ->  https://<domain>/  ->  Caddy (HTTPS)  ->  127.0.0.1:8088
                                               |- /curseforge/* -> api.curseforge.com (x-api-key injected)
                                               |- /modrinth/*   -> api.modrinth.com
                                               |- /files/*      -> edge.forgecdn.net (key injected when set)
                                               \- /data/*       -> cdn.modrinth.com
